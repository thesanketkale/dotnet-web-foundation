# Security Policy

## Supported Versions

Only the latest release on the primary development branch receives active security updates and vulnerability patches.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

We take the security of `dotnet-web-foundation` seriously. If you discover a vulnerability, please do NOT file a public issue.

### Preferred Reporting Method
Please report security vulnerabilities through [GitHub Private Vulnerability Reporting](https://github.com/thesanketkale/dotnet-webapp-template/security/advisories/new).

Alternatively, you can email security reports to [security@thesanketkale.com](mailto:security@thesanketkale.com).

### Information to Include
- A detailed description of the vulnerability.
- Steps to reproduce or proof-of-concept (PoC) code.
- Potential impact and affected components (e.g. Identity, CMS, File Storage, Middleware).
- Suggested remediation or workaround if available.

### Response Timeline
- **Initial Response:** Within 48 hours acknowledging receipt of the report.
- **Triage & Status Update:** Within 5 business days detailing validation results and target fix timeline.
- **Disclosure:** We follow coordinated disclosure. Fixes will be released via a patch version alongside a GitHub Security Advisory.
